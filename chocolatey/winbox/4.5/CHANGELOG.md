## WinBox 4.5 - [Changelog](https://forum.mikrotik.com/t/winbox-4-5-released/274230)

### What's new in 4.5 (2026-11-03):

* ui: rewrite combobox to support filtering/suggestions;
* app: ignore QML_DISABLE_DISK_CACHE env variable in case user has set it somehow;
* routeros-api: add support for new ui types;
* table: compact enable/disable/remove/comment buttons when there is no space;
* table: optimize fields where data are retrieved from other table (e.g. DHCP Leases -> Bridge Port);
* table: optimize large ordered list rendering (e.g. Log);
* table: show tools in toolbar as buttons if there is space available;
* ui: add topology support;
* ui: change text selection color in dark mode;
* ui: make input field and table cell text color brighter in dark mode;
* ui: rework bar graphs ui;
* ui: update and add new icons;
* ui: update icons for users tables;
